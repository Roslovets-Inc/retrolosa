# Toulouse · Сквозь время

Локальный прототип: современная векторная карта + географически привязанная отрисовка кадастра около 1680 года.

## Запуск

Требуется Node.js 22.12+ (проверено с 24).

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Для карт нужен интернет. Сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Возможности

- Шторка и наложение с непрерывной регулировкой.
- Быстрое переключение 1680 / Сегодня; удержание пробела показывает современную карту.
- Переходы к Rue Ninau, Saint-Étienne, Saintes-Scarbes, Montoulieu и центру.
- Общая камера для обеих карт, масштаб, координаты и ссылка на выбранное место.
- Адаптивный интерфейс и панель источников/ограничений.

React 19, TypeScript, Vite 8, MapLibre GL JS 6, PMTiles 4. Без бэкенда и API-ключей. Современная подложка OpenFreeMap/OSM; исторические тайлы Makina Corpus/Toulouse Métropole.

## Проверка

При работающем локальном сервере: `npm test`. Интеграционная проверка использует установленный Microsoft Edge и реальные сетевые источники (не заглушки); ей нужен интернет. Проверяет загрузку, переключение, прозрачность, шторку, клавиатуру, переходы и мобильную компоновку. Снимки в `.local/`.

## Историческая достоверность

Слой 1680 — современная визуализация исторического кадастра, **не архивный скан**. Привязка взята у источника и не корректировалась вручную. Абсолютная точность не сертифицирована. Полная проверка источников и ограничения публикации: [docs/sources.md](docs/sources.md). Эта версия предназначена для локальной проверки концепции; внешняя публикация не выполнена.
