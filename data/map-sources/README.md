# Preserved original map images

Original scans and figures are retained here independently of the editor. The public copies remain available for existing source links. Current user annotation projects and GDAL reports remain in `../georeferencing/`; other historical control points and reports remain in `../`. These records are not imported by the website runtime. Prepared display assets remain in `public/` with their Items in `data/stac/`. Never overwrite an original when preparing a new revision.
